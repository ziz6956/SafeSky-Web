# SafeSky

SafeSky — информационно-технологический сервис персонального оповещения.

Сервис следит за открытыми сообщениями о воздушной опасности в регионе пользователя и доставляет критически важные уведомления через телефонный звонок.

> SafeSky — неофициальный сервис. Он не заменяет МЧС и региональные системы оповещения и не является их частью.

## Интерактивный прототип

В этом репозитории размещён интерактивный прототип лендинга, регистрации и личного кабинета:

**https://ziz6956.github.io/SafeSky-Web/**

Сценарий прототипа: лендинг → «Зарегистрироваться» → номер телефона (маска +7) и обязательное согласие на обработку персональных данных → «Получить код» → ввод 6-значного кода (демо-код `123456`, три попытки) → личный кабинет (номер только для чтения, селектор аэропорта, тумблер звонков, статус).

Все данные в прототипе демонстрационные: введённый номер никуда не отправляется и не сохраняется — это макет для проверки визуала и переходов.

## Макеты

Изображения макетов в высоком разрешении лежат в [`design-mockups/`](design-mockups/) — 13 экранов, у каждого версии Desktop и Mobile (26 PNG).

## Как устроен прототип

`index.html` — самодостаточный бандл: стили и шрифт Inter встроены, интернет при открытии не нужен. Исходники вёрстки — в [`src/`](src/): `content.js` (тексты), `landing.js` и `lk.js` (экраны), `theme.js`, `svgkit.js`.
