SafeSky — прототип
Экран
Кликните подсвеченные зоны. Путь: лендинг → «Зарегистрироваться» → регистрация по номеру телефона → код из SMS → учётная запись создана → личный кабинет. Ниже — отдельно показаны состояния: ошибки формы, неверный код, заблокированный код и прежние разделы ЛК (События / Настройки / Тарифы / Подписка).
Формы заполняются по-настоящему. На регистрации телефон обязателен (маска +7), согласие на обработку персональных данных обязательно и по умолчанию снято. На экране кода — 6 цифр, 3 попытки на код и таймер повторной отправки 30 секунд; демо-код — 123456, третья ошибка ведёт на экран блокировки. SMS не отправляется: это демо-режим.
Запуск локально: python3 -m http.server 8080 из папки prototype/, затем http://localhost:8080 Обновить макеты: node build.js
