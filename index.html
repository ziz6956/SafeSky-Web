SafeSky — прототип
Экран
Кликните подсвеченные зоны. Путь: лендинг → «Записаться в список на запуск» → форма (телефон + Email/Telegram + регион + 2 отдельных согласия) → подтверждение → личный кабинет (События / Настройки / Тарифы / Подписка), плюс пустое состояние истории событий.
Форма на экране «Список на запуск» заполняется по-настоящему: телефон обязателен, два согласия обязательны и по умолчанию сняты — пока их не отметить, отправка не пройдёт.
Запуск локально: python3 -m http.server 8080 из папки prototype/, затем http://localhost:8080 Обновить макеты: node build.js
